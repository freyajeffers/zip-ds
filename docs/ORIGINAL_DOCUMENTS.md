# Original project documents

The files in this directory with descriptive source-document names are the original project-creation and development specifications from which the current implementation was built.

They are retained as historical/design references, not as claims that every planned component is implemented. For the current checkout, use these documents first:

- `DEVELOPMENT.md`: current dependency order, commands, and module boundaries.
- `INVARIANT_AUDIT.md`: verified invariants and explicitly incomplete phases.
- Root `README.md`: current capabilities, setup, public API, and limitations.
- Root `AGENTS.md`: mandatory instructions for coding agents.

The original documents describe the intended five-phase system, including future retrieval, semantic alignment, reporting, REST, and deployment work. Check the current README and invariant audit before treating any specification item as implemented.
